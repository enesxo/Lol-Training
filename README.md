# Hextech Arena

Ein kleines Browser-Spiel im Stil von League of Legends mit zwei Modi:

- **Dodge:** Weiche den Projektilen aus und halte so lange wie möglich durch.
- **Last Hit:** Hole so viele Minions wie möglich mit dem letzten Treffer. Ziel: 107 CS bis 10:00.

## Spielen

Einfach die Seite öffnen, es muss nichts installiert werden. Für die Champion-Auswahl im Last-Hit-Modus ist eine Internetverbindung nötig, weil Champion-Liste und Icons von Riots Data Dragon geladen werden.

**Steuerung:** Rechtsklick bewegt die Figur bzw. greift einen Minion an, `S` stoppt, `W` ist der Dash (nur Dodge), `Esc` pausiert.

Bestenlisten werden nur im eigenen Browser gespeichert.
